# 한글 수호대 — 잃어버린 한글을 찾아서

6학년 한글날 2차시(80분) 협력 수업용 도트 RPG 웹앱입니다.
학생은 아이패드(1인 1대)로, 선생님은 전자칠판으로 접속해요. 모둠끼리 경쟁하지 않고, **반 전체가 목표 문장을 함께 복원**해야 보스 묵귀를 물리칠 수 있어요.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생 화면 (아이패드 가로) |
| `teacher.html` | 선생님 화면 (전자칠판) |
| `js/config.js` | 로컬 테스트용 (배포 때는 Vercel 환경변수로 자동 생성) |
| `scripts/build.js`, `vercel.json` | Vercel 배포 설정 — 고칠 필요 없어요 |
| `js/content.js` | 퀴즈, 단서, 대사, 맵 — **문제를 고치고 싶으면 여기** |
| `supabase/schema.sql` | 데이터베이스 설정 (한 번만 실행) |

---

## 1. 먼저 내 컴퓨터에서 시험해 보기 (설치 없이)

- **혼자 체험:** `index.html?demo=1` 로 열면 혼자 모든 역할을 맡고, 다른 4개 모둠은 자동으로 움직여요.
- **여러 명 흉내 내기:** `config.js`가 비어 있으면 「로컬 테스트 모드」예요. 같은 브라우저에서 `teacher.html` 탭 1개 + `index.html` 탭 여러 개를 열면 서로 연결돼요. (탭마다 닉네임을 다르게 넣어 주세요.)

> 파일을 더블클릭해서 열면 일부 기능이 막힐 수 있어요. VS Code의 Live Server 같은 간단한 로컬 서버로 여는 걸 추천해요.

## 2. 연결하기 — GitHub → Supabase → Vercel

자세한 클릭 순서는 **`환경변수_설정_가이드.md`** 에 따로 정리했어요. 요약하면:

1. **GitHub:** 새 저장소에 이 폴더 파일을 모두 올려요. (`js/config.js` 는 비워 둔 그대로!)
2. **Supabase:** 새 프로젝트 → SQL Editor 에서 `supabase/schema.sql` 실행 → Project URL 과 anon(publishable) 키 복사
3. **Vercel:** 저장소 Import → **Environment Variables** 에 두 개 넣고 Deploy

| 이름 (Key) | 값 (Value) |
|---|---|
| `SUPABASE_URL` | `https://abcdefgh.supabase.co` |
| `SUPABASE_ANON_KEY` | `eyJ...` 또는 `sb_publishable_...` |

배포할 때 `scripts/build.js` 가 이 값으로 `config.js` 를 자동으로 만들어요. 키가 GitHub에 올라가지 않아요.
Vercel의 Supabase 연동(Integrations)으로 자동 생성된 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` 이름도 그대로 인식해요.

## 3. 주소와 확인

- 학생: `https://내프로젝트.vercel.app`
- 선생님: `https://내프로젝트.vercel.app/teacher.html`
- 선생님 화면 첫 화면 아래에 **🟢 Supabase 연결 설정됨** 이 보이면 성공이에요.
  🟡 이면 환경변수가 안 들어간 것, 🔴 이면 원인 안내가 함께 나와요.
- 문제를 고치고 GitHub에 다시 올리면 Vercel이 자동으로 새로 배포해요. **환경변수를 바꾼 뒤에는 Redeploy를 꼭 눌러야** 반영돼요.

## 4. 아이패드 준비 (수업 전에 한 번)

- 사파리로 학생 주소 접속 → 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면이에요.
- 가로 모드로 사용해요. (세로로 들면 "가로로 돌려 주세요" 안내가 떠요.)
- 첫 화면을 한 번 터치해야 소리가 나요. (아이패드 규칙)
- 소리는 메뉴(☰)에서 끌 수 있어요.

## 5. 수업 흐름

| 시간 | 선생님 화면 | 학생 |
|---|---|---|
| 도입 | **방 만들기** → 입장 코드 4자리를 칠판에 띄우기 | 코드·모둠·닉네임 입력 → 대기실에서 내 역할 확인 |
| | **이야기 보여 주기**로 프롤로그 함께 보기 | 역할 바꾸고 싶으면 「역할 바꾸기」 |
| 전개 | **모험 시작** → 진행판으로 모둠 살피기, 막힌 모둠에 **힌트 보내기** | 맵 1~4 임무 해결, 먼저 끝난 모둠은 힌트 두루마리 보내기 |
| | 설명이 필요하면 **일시정지** | |
| 보스 | 모든 모둠이 글자를 찾으면 자동 시작 (급하면 **보스전 바로 시작**) | 문제 맞혀 공격, 먹물 얼룩은 눌러서 닦기 |
| 정리 | 엔딩 → **결과 보기**로 많이 틀린 문제 짚기 | 임명장 길게 눌러 저장 |

**역할:** 모둠 인원에 따라 자동으로 나눠요. 3명이면 한 명이 대장·조립왕·힌트 지킴이를 함께 맡고, 5명이면 다섯 역할이 하나씩, 6명부터는 탐정이 둘이 돼요. 수업 중 누가 나가도 남은 친구에게 역할이 넘어가요.

**같은 아이패드에서 다시 들어오기:** 같은 방 코드 + 같은 닉네임으로 들어오면 같은 학생으로 인식해 역할 순서가 유지돼요.

## 6. 내용 바꾸기

- **목표 문장, 모둠 수:** 선생님 화면에서 방을 만들 때 바로 정해요 (2~8모둠). 글자는 앞에서부터 고르게 나눠져요.
- **퀴즈, 단서, 대사:** `js/content.js` 의 `Q`, `clues`, `talk`, `BOSS_QUESTIONS` 를 고치면 돼요. 3지선다이고 `a`는 정답 번호(0부터 시작)예요.
- **보스 체력:** `js/net.js` 의 `HS.BOSS_PER_TEAM` (모둠당 25).

## 7. 문제가 생기면

- **"방이 없어요"** → 선생님 화면의 코드를 다시 확인. `config.js`가 학생/선생님 모두 같은 Supabase를 보고 있는지 확인.
- **진행이 늦게 반영돼요** → 학교 와이파이가 잠깐 끊겨도 8초마다 다시 맞춰요. 계속되면 새로고침해도 진행은 저장돼 있어요.
- **오래된 방 정리** → `schema.sql` 맨 아래 정리용 줄을 참고하세요.
